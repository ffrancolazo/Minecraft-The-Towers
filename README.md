# Proyecto Minecraft

Entorno de desarrollo personal con foco en Java y plugins de minecraft usando la API de Paper.

## Acerca de

Este repositorio contiene plugins de Minecraft desarrollados de manera independiente, documentación técnica, notas de desarrollo y configuraciones de infraestructura.

El objetivo principal es aprender, experimentar y aplicar principios de desarrollo de software a través de proyectos prácticos.

El desarrollo es llevado a cabo localmente usando VSCodium, mientras una maquina virtual con Ubuntu aloja el servidor Paper de Minecraft.

Los plugins son compilados con Gradle y desplegados remotamente usando SSH/SCP.


## Tecnologias

- Java
- Paper API
- Gradle
- Git / GitHub
- Linux / Ubuntu
- SSH / SCP
- tmux
